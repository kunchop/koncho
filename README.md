# Koncho - A Fantasy Adventure Game

## Overview
Koncho is an interactive fantasy adventure game with a rich storyline, character progression, and branching narratives. Players embark on an epic quest filled with challenges, mysteries, and memorable characters.

## Features
- **Engaging Storyline**: A branching narrative with multiple paths and endings
- **Character Development**: Level up, gain skills, and acquire legendary items
- **Dynamic Choices**: Your decisions shape the world around you
- **Fantasy World**: Explore dungeons, cities, and mystical forests
- **Combat System**: Strategic turn-based battles against monsters and enemies

## Getting Started

### Installation
```bash
npm install
```

### Running the Game
```bash
npm start
```

## Story Summary
You are an adventurer awakening in the mystical realm of Aldermoor. Dark forces are stirring, and ancient prophecies speak of your arrival. Will you become a hero, or will you succumb to the darkness?
